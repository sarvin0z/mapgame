# UTD EMS Cart Simulator: handoff

This is a browser-based 3D recreation of the University of Texas at Dallas campus. You drive the UEMR (University Emergency Medical Response) golf cart around it. As of 2026-11-01 the game runs, the tests and production build pass, and work is iterative: the user reviews screenshots and sends lists of fixes.

Read this first, then `README.md` (how to run it, the data pipeline and the folder layout) and `docs/ISSUES.md` (every change, with numbered entries #1–#163, plus the **Open** list).

---

## 1. Quick start

```bash
npm install          # node_modules is not in the zip
npm run dev          # http://localhost:5173
npm test             # vitest, 55 tests
npx tsc --noEmit     # typecheck
npm run build        # tsc + vite build -> dist/ (static site)
```

- **Requirements:** Node 22+ (it was run on Node 26; the `scripts/*.ts` run directly with `node`) and Blender 5.2 for the asset generators.
- **URL options:**
  - `?quality=low|medium|high` turns adaptive quality off.
  - `?time=golden|day|night` sets the time of day.
  - `?spawn=<building name>` picks the start building.
- **Controls:** F1 in the game shows them all.
  - W/A/S/D or the arrow keys drive.
  - L, K, H and B toggle the lights, headlights, siren and horn. These are also clickable chips on screen.
  - C cycles the camera, I toggles the location card and Esc opens the menu.

## 2. The user's hard constraints (keep these)

- **Google 3D Tiles:** do not scrape, extract, trace or reconstruct geometry from Google Photorealistic 3D Tiles. Use Google imagery only as its licence allows.
- **Unmapped geography:** do not invent building positions or pathways where no geographic information exists. Log uncertain or missing geography separately, in `docs/ISSUES.md` (Open) and `data/verification/`.
- **Site knowledge:** the user knows the campus first-hand. Their corrections override OSM, and each one is recorded as a named override in code with a comment (see §6).
- **Commits:** commit only when the user approves. The repo was just `git init`-ed and has no commits yet. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## 3. Stack and architecture

TypeScript, Three.js 0.187 (WebGL), Rapier 3D 0.21 (physics), Vite 8, Vitest. Blender 5.2 generates assets headless.

- **Coordinates:** map points are `Pt = [east, north]` in metres from 32.9858° N, 96.7503° W. In the world, x is east, y is up and **z is −north**, so map `[x, y]` becomes world `(x, h, -y)`. Mixing these up is the most common bug.

## 4. Asset generators (Blender, headless)

Use the full path from bash. The npm scripts fail under cmd.exe because of the quoting.

```bash
"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --factory-startup --python blender/build_buildings.py -- reconstruction/specs.json public/models/buildings [slug]
"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --factory-startup --python blender/build_cars.py -- public/models/cars.glb
"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --factory-startup --python blender/build_cart.py -- public/models/uemr_cart.glb
"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --factory-startup --python blender/to_webp.py -- public/textures
```

- **Building recipes:** each building's recipe is in `reconstruction/specs.json`, with keys such as `facade`, `ground`, `roof`, `recess`, `lantern` and `accent`.
- **Rebuilding one model:** passing a slug rebuilds only that building. `index.json` is now rebuilt from every `.glb` in the folder. An earlier bug wrote only the rebuilt slug, which dropped 30 buildings back to boxes.
- **Photo textures:** the ones in `public/textures/` were generated by GPT-6 Luna with gpt-image, through the `opus-luna-orchestrator` skill and `codex exec`, then made seamless.

## 5. Verification workflow (how changes were checked)

The dev server has `POST /__capture?name=x`, which saves a PNG to `data/preview/x.png`. With `npm run dev` running, the browser console exposes `window.__h`:

- **`__h.capture(name, posVec3, lookVec3)`:** renders a 1280×800 frame through post-processing.
- **`__h.captureCart(name, eye, at)`:** the same, with camera offsets in the cart's local frame.
- **`__h.compare(buildingName, refFile)`:** renders the building next to a photo from `data/refs/`.
- **`__h.flicker(name, [x,y,h], [x,y,h])`:** renders the view twice, 2 cm apart, with the tree sway frozen. It returns the number of flagged 16 px blocks and saves `<name>_flick.png` with z-fighting marked in red.
- **`__h.place(pt, dir)` and `__h.sim(secs, controller)`:** deterministic physics, used for example to check that a passage is drivable.
- **`__h.profile()`:** frame milliseconds, draw calls and triangles. Timings are unreliable while the browser pane is hidden (it throttles); trust triangle and call counts.

`window.__sim` exposes `cart`, `scene`, `data`, `terrain`, `renderer`, `rc` (via the menus) and `freezeFoliage`.

## 6. User-requested site corrections (in code, not in OSM)

- **`campusData.ts`:**
  - **`BUILDING_OVERRIDES`:** Callier Center Richardson (two storeys, orange accents), the Athenaeum Performance Hall (finished), the JSOM facade, and Comets LANding (three storeys, 15.5 m, grey-framed glass).
  - **`REMOVED_BUMPS`:** the raised table on Drive H at the University Village exit.
  - **`openMedians`:** inferred medians open wherever a road crosses them.
  - **`hugRoundabout`:** the sidewalk round the central roundabout runs along its curb.
- **`routeChallenge.ts`:** excludes Waterview Science and Technology Center and every `Northside*` building (UEMR no longer responds there).
- **`landmarks.ts`:** the Union steps are Ipe-wood seating steps on Comets LANding's north side, climbing to the second-floor deck. Placement follows the user's description; there are no photos of it.
- **`scripts/process-osm.ts`:** lot names come from OSM `ref` (Lot J, Lot M East, …), because the current snapshot has no `name` on them.

## 7. Gameplay rules (current)

- **Route Challenge modes:** Random, Choose (buildings and named lots), and Multi-stop (2–10 random stops or a chosen list, with a time per stop and a total).
- **Arrival:** within 6 m of any wall of the building, or inside the lot.
- **Score out of 1000:**
  - 40% route efficiency, 30% pace (7 m/s reference), 15% staying on roads and walks, 15% traffic.
  - Traffic means a rolling stop at stop signs (≤ 1.3 m/s) and ≤ 3.6 m/s over speed bumps.
  - −50 per pedestrian contact and −100 per collision. A collision is a speed loss above 1.6 g.
  - Showing the best route and showing the destination beam each cost 10%; both are off by default.
- **Horn and siren:** the horn is a one-second press. While the horn or siren sounds, people get out of the cart's way.

## 8. Known gotchas

- **Bash heredocs:** on this Windows machine they break on quotes. Write patch scripts to a file with the Write tool, then run them with `PYTHONUTF8=1 python -I file.py`.
- **Shader cache keys:** `onBeforeCompile` cache keys must be unique per material. `reflections.ts` captures the original key; an earlier version mixed up shaders across materials.
- **No grading:** do not level or grade the terrain around buildings. It was tried (`gradeSites`) and reverted because it made the ground worse.
- **Cart reflections:** do not apply the reflection boost to the cart. It made the clear windshield flash white.
- **Shadow map:** it updates every frame. Alternate-frame updates looked like flicker.
- **Two raw OSM files:**
  - `data/raw/utd-osm.json` is current, and the processor reads it.
  - `utd-osm-2026-07.json` is an older snapshot that still has lot `name` tags.
  - Re-running `process-osm.ts` regenerates `public/data/campus.json`.
- **Model overlap:** the Student Union GLB overlaps Comets LANding and a canopy (the east arcade). The physics and the foundation walls skip any part of a footprint that a canopy covers.

## 9. Open items (see `docs/ISSUES.md`, Open)

- Where divided roads meet other roads, small grass gaps remain between the two carriageways (needs junction polygons).
- JSOM and Callier are procedural boxes with new facades, not full models. The Student Union steps and Comets LANding follow the user's description, not photos.
- Collision detection infers impacts from deceleration and misses slow scrapes; Rapier contact events would catch those.
- The leaf texture shows large individual leaves up close. Lit windows at night are random. Frame time on High is about 25–30 ms on integrated graphics; adaptive quality steps down.
- The user has not yet confirmed the new siren and horn sounds.
